Welcome - CAD Profile Generator

Purpose

The purpose of this tool is to help architects to build 3D profiles from 2D drawings.
Instead of doing the calculation manually, this tool extracts the length of the profile from the uploaded drawing and scales it.
The user inserts the height for each segment and groups them into layers.
Each layer will correspond to a profile.
The user can also choose which segments they want to remove the paper width from.
Finally, the tool will generate a profile per layer, which the user can print and use to cut the material for the 3D profile.
The profiles are identified by the layer number, and each layer number has a numbered segment, so the user knows how to assemble it. On the example below the user sees that segment 5, which accounts for the paper width, fits into segment 3.
